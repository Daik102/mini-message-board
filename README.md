<h1>Project: Mini Message board</h1>

A mini message board app with several features<br>
This project is based on <a href="https://www.theodinproject.com/">The Odin Project</a>.

<h3>Features</h3>

- Dynamic routing with route parameters

- EJS for server side rendering (SSR)

- express-validator for server side validation

- Custom error handling (404, 500)

<h3>Tech Stack</h3>

- Frontend: EJS, CSS

- Backend: Node.js, Express, express-validator, serve-favicon

- Icons: Pictogrammers
